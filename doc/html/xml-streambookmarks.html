The QXmlStream Bookmarks example provides a reader for XML Bookmark Exchange Language (XBEL) files that uses Qt's QXmlStreamReader class for reading, and QXmlStreamWriter class for writing the files.

See the XML Bookmark Exchange Language Resource Page for more information about XBEL files.
